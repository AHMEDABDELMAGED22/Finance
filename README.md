# فلوسي — My Money Manager

تطبيق مالي شخصي متكامل ومخصص لمدرّس حر في مصر لإدارة مصادر الدخل المتعددة، السناتر والطلبة، الحصص، المصاريف، المحافظ المالية، والالتزامات.

## ✨ الميزات الرئيسية

### 1. إدارة السناتر والطلبة المخصصة
- **سنتر الفاروق:**
  - 3 مجموعات مخصصة بفلترة وإحصائيات مستقلة:
    1. **تانية بكالوريا عربي**
    2. **تانية بكالوريا لغات**
    3. **أولى ثانوي لغات**
  - أزرار اختيار سريعة عند إضافة/تعديل الطالب
  - خيار استلام الطالب للدفع: (أنا مباشرة أو السنتر) مع تحديد نصيبي ونصيب السنتر بدقة.
  - عدم إضافة مبالغ السنتر للمحفظة حتى تتم التسوية الفعلية.

- **سنتر المنارة وسنتر رؤية:**
  - واجهة مبسطة لاستلام الدفعات مباشرة من السنتر (`استلام دفعة من السنتر`).
  - كشف تسويات فوري ومتابعة المستحق طرف السنتر وما تم استلامه فعلاً.

- **سنتر 4GEEKS:**
  - تحصيل ذاتي من الطلبة.
  - زر مخصص لـ **خصم ودفع إيجار القاعة (40 ج.م/حصة)** يخصم المبلغ من المحفظة المحددة (كاش، فودافون كاش، إنستاباي) ويسجله كمصروف عمل.
  - سجل كامل لإيجار القاعات وحساب **صافي العائد الفعلي بعد خصم الإيجار**.

### 2. لوحة التحكم (الرئيسية)
- إجمالي الرصيد الفعلي ورصيد المتاح للإنفاق بعد حجز الالتزامات.
- أرصدة المحافظ الثلاثة: **كاش**، **فودافون كاش**، **إنستاباي / بنك**.
- ملخص الدخل والمصاريف الشهرية وصافي الدخل.
- أزرار الوصول السريع: إضافة دخل، إضافة مصروف، تسجيل حصة، تحويل بين المحافظ.
- متابعة الالتزامات القادمة وشريط التقدم.

### 3. المعاملات المالية
- سجل المعاملات مصنف (دخل، مصاريف، تحويلات).
- إمكانية **تعديل وحذف أي معاملة** بنقرة واحدة مع ضبط أثر المحافظ تلقائياً.
- تفاصيل المصاريف حسب التصنيف ونسبتها.

### 4. الالتزامات المالية
- الجمعية الشهرية (7,000 ج.م شهرياً).
- مصاريف الكلية (7,000 ج.م).
- نظام حجز افتراضي يخصم من المتاح للإنفاق فقط دون خصم نقدي من المحافظ.
